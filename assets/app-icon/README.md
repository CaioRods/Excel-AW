# Ícone do ExcelAW

Identidade visual preparada a partir da imagem fornecida pelo usuário para o ExcelAW: composição vermelha e amarela com a letra X branca, em fundo transparente. A cor principal da interface é `#e31923`.

`gridcraft.svg` contém o PNG incorporado para preservar a aparência da referência. Os nomes dos arquivos e o identificador do pacote são mantidos por compatibilidade com os scripts e recursos do aplicativo.

Os arquivos derivados incluem PNG de 16 a 1024 pixels, ICO para Windows e ICNS para macOS. O ícone do macOS usa a margem transparente da grade de 824/1024. `packaging/icons.sh` regenera os arquivos a partir do SVG; ICNS requer `iconutil` no macOS.

A origem e a autorização de uso estão em `LICENSE.txt` e na tabela `ATTRIBUTION.md`.
